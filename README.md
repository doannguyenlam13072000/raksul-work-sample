## Testing

Unit tests were implemented to verify the expected behavior of the application.

To run the tests:

```bash
yarn test
```

To run the tests with coverage:

```bash
yarn test --coverage
```

## Development

Install dependencies:

```bash
yarn install
```

Start the development server:

```bash
yarn dev
```
